## Verified original D3D9 shader structure

User's original PC SHADEREF(1).ARC has 36 original ShaderEffects records.
It contains **98 VS + 98 PS CTAB tables**, read directly from original
SM2 bytecode. **91 vertex programs use ViewProj c11–c14** and **81 use
World c7–c10**. All 91 ViewProj tables define D3DX register set 2,
parameter CLASS 3 (MATRIX_COLUMNS), type 3 (FLOAT), rows 4 and columns 4.
The original shader vertex position therefore has a known candidate
constant layout for changing clip-space X on native PC D3D9.

PCGamingWiki confirms that the original Hulk PC is Vert-minus with
wider aspect ratios:
https://www.pcgamingwiki.com/wiki/The_Incredible_Hulk_%282008%29

Experimental Hor+ adjustment for a 16:10 back buffer is
`x_scale = (4/3) / (2560/1600) = 5/6 ≈ 0.8333333`.
For 16:9 it is `(4/3)/(16/9)=0.75`. A shader which interprets the
original matrix differently could need a different operation; this has
NOT been visually verified in Hulk gameplay. Never edit UI matrices
or assume the ASI corrects the game-wide FOV automatically.

The enhanced Win32/x86 ASI hooks the original D3D9 COM interface (the
same interface returned by DXVK's 32-bit d3d9.dll), reads actual CTAB
on shader creation, and guards the optional ViewProj correction on
the original vertex shader having **both ViewProj and World**.
Includes a reversible NoFov preset with no projection changes.

## FPS: exact DXVK options

Upstream DXVK documents the following:
- `d3d9.presentInterval = 0` disables presentation VSync.
- `d3d9.maxFrameRate = 30/60/120` caps DXVK output at that rate.
- `d3d9.maxFrameRate = -1` disables DXVK's own limiter.
- `d3d9.maxFrameRate` cannot remove an internal game simulation
  limiter, and does not decouple Havok, missions, physics or animation.

Source: https://github.com/doitsujin/dxvk/blob/master/dxvk.conf

The separate prebuilt experimental pack contains a PowerShell
installer that **backs up the user's existing dxvk.conf** and changes
ONLY these two DXVK options. It also validates the exact HULK.EXE SHA
`6d71e479de73a5e3ee5f3a924ed2dc6f79aea9f0aac43b5984b1f77193d3b233`,
backs up the user's old HulkPC.ini and known original ASI files, and
refuses to overwrite unknown third-party modules. No original PC
assets, save files, DXVK d3d9.dll or HULK.EXE are distributed or altered.
