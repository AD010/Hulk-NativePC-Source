# Native shadow admission of observed FMOD waveforms

The previous read-only direct instance capture now additionally rejects a nonempty sound-instance child list (+120, seen in 8283A3D8..8283A57C) rather than claiming completeness for shared/polyphonic voices. The observed layer/instance/variant ordinal, source SoundDef name, variant count and selected weight must agree with the source FEV definition. A non-wave entry cannot be admitted as PCM. Synthetic observation tests plus traversal of the original source corpus on GCC and Clang cover 744 projects, 12282 source waveform references and 201 non-wave choices. These are source reference counts (including repeated references), not actual live sound starts.

With both HULK_EXPERIMENTAL_NATIVE_FMOD=1 and HULK_EXPERIMENTAL_NATIVE_FMOD_SHADOW=1, the original game update may now create an actual native XAudio2 voice through the existing indexed sample or named DSP route when an observed direct selection is validated. The native mixer is muted to avoid duplicate audible original output. A bounded registry deduplicates starts by event owner/project/start stamp/instance/channel/variant, records rejected starts, and stops voices whose observed generation/selection is gone. Incomplete snapshots do not imply disappearance. At most one new cue per 100ms diagnostic snapshot; synchronous decode may cause stalls, so the shadow mode is not enabled by default. The source archive must exist and pass the existing index/record validation. Bus Sfx is a diagnostic placeholder; current DSP parameters are a single snapshot. Playback does not reproduce the actual original channel cursor, loops, spatial transforms, ongoing parameter changes, nested sound-instance selection, or exact mixing. Windows compilation and in-game execution remain unverified. No original audio is suppressed.
