## Native shadow spatial playback

Original min/max distance fields +320/+324 are independently confirmed by the USA setter 82795C40 (called via 82787BF0 at 82839814), and getter 82791E20. The shadow observer now supplies these values, sound mode and listener/source position to X3DAudio during start and subsequent parameter updates. Old FMOD Ex mode bits and handedness are cross-referenced against the 4.24.16 header; the native model uses linear or unit-factor inverse-distance attenuation and rejects custom curves. X3DAudio is used for directional coefficients with a unity volume curve when the native approximation supplies distance gain, avoiding double attenuation of the 3D leg. FEV Pan3DLevel blends the flat and spatial matrices. DSP-backed voices can update coordinates/pan/3D blend without restarting or refiltering PCM. The real original mixer is still authoritative and the shadow remains muted. This is not a bit-exact FMOD mixer or full ABI replacement; custom curves, exact global rolloff, cones, occlusion, Doppler, original stereo emitter law, multiple listeners and the Windows build/game test are not verified. The spatial math and synthetic memory capture test passed locally with GCC and Clang C++20; Windows-specific code has not been compiled.
